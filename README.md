# TowerDefenseGame 🛡️✨

## 🎯 Overview

**TowerDefenseGame** is a 3D tower defense game built with **Unity (C#)** where players strategically place defensive towers to protect their base from waves of enemies. This project showcases core gameplay mechanics such as tower placement, different behaviors for enemies and towers and wave progression.

---

## 🕹️ Gameplay

- 🎯 Players defend against waves of enemies advancing towards the castle.
- 🏗️ Towers can be placed in one of the five lanes to stop enemies.
- ⚔️ Enemies follow paths and try to reach your base.
- 💪 Waves increase in difficulty as the game progresses.

The goal is simple: **survive as long as possible by planning your defense wisely!**

---

## 🧠 Features

- 🥷 Different types of towers and enemies, each with unique abilities and animations
- 📖 Encyclopedia - easily check what each tower and enemy does, directly in game!
- 🌆 Different scenes for each level
- ⏩ Fast forward button
- 🔊 Settings menu
- 🧩 Modular Unity structure — easy to expand
